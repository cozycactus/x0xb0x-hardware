# Revision 28 verification

The saved-file audit compares revisions 27 and 28, accepting only the eight chip objects added, the eight SIP pair objects removed, the eight mainboard layer meshes, three added and two retired materials, the source fields and the new guide. Every other object, pose, camera, legend and animation remains. It reads the chips' positions from the PCB file. The layer audit compares the saved layer meshes with a fresh KiCad export, since the shared model check leaves the board out, and checks the chip lands, the SIP pads and the vias against the PCB file. The contact screen tests the evaluated chip instances against every other visible mesh at frame 1, and the SIP pairs in revision 27 the same way. The other scripts replay the current native-model, drill-fit, portability and terminal-join checks; source hashes are pinned in their reports. Before/after detail images use identical cameras and nothing is saved.
