# Revision23 verification

The saved-file audit compares revision22 and23, accepting only14 declared PTC mesh changes, two roots' source fields and the new guide. Every existing object, material, pose, camera, legend and animation remains. The other scripts replay current native-model, lead/drill, portability and terminal-join checks. Source hashes are pinned in their reports.

Before/after detail images use the same camera scale; installed-detail lighting is temporary and never saved. The neighbour screen tests actual evaluated PTC instances against other component/panel/enclosure meshes, excluding their own geometry and expected PCB seating contacts. It is a triangle-contact screen, not a physical assembly or tolerance qualification.
