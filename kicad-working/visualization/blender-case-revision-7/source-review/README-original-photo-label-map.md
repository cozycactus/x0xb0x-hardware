# Approximate editable original-photo labels

`original-photo-label-map.json` contains 100 editable text labels in original
DXF millimetre coordinates. `original-photo-label-layout.svg` is an editable
vector layout containing text and one approximate separator line. It embeds
no photograph. `original-photo-label-diagnostic.svg` and its PNG preview add
original mechanical cutouts as a registration guide.

The 1499 × 1114 pixel photograph comes from Ladyada's original project page.
A four-corner planar calibration relates the original flat panel to the DXF
outline. Five independent screw-centre readings differ by at most 1.027 mm;
positions should be treated as approximate to about 1.5 mm. Lens distortion,
corner readings and text-centre readings are uncorrected. Arial/Helvetica,
font size and tracking are presentation approximations. This is not original
manufacturing artwork.

The mapping includes SAW/SQR, all primary controls, 16 mode-selector legends,
1–16 bank ring labels,1–16 step-LED numbers, keyboard notes, function buttons,
1–8 white-key labels and the original top-edge rear-port names. Bank positions
1 and 16 are hidden by the elevated knob in the reference photo and are marked
as sequence-based inferences. The other numeric ring positions use a regular
16-position layout approximated from the visible ring.

The vector omits invented x0xb0x and SYNTHESIZER / SEQUENCER titles and the
generic WAVEFORM/BANK/MODE labels. These words do not appear on the original
photographed panel. S17–S24 white and all 15 other cap colors are confirmed.
