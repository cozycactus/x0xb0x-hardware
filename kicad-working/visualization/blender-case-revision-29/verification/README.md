# Revision 29 verification

The saved-file audit compares revisions 28 and 29, accepting only the four chip objects added, the four TO-92 JFET objects removed, the eight mainboard layer meshes, three added materials and any retired ones, the source fields and the new guide. Every other object, pose, camera, legend and animation remains. It reads the chips' positions from the PCB file. The layer audit compares the saved layer meshes with a fresh KiCad export, since the shared model check leaves the board out, and checks the chip lands, the JFET holes' pads and the vias against the PCB file. The contact screen tests the evaluated chip instances against every other visible mesh at frame 1, and the JFETs in revision 28 the same way. The other scripts replay the current native-model, drill-fit, portability and terminal-join checks; source hashes are pinned in their reports. Before/after detail images use identical cameras and nothing is saved.
